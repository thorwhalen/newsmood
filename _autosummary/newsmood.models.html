newsmood.models#

Baseline walk-forward modeling on the news-feature panel.

A deliberately small surface aimed at the first vertical slice:

  • walk_forward_splits(): expanding-window splits with an embargo, so no test fold can leak information from training (forward-return overlap).

  • information_coefficient() / rank_information_coefficient(): the two metrics the user’s hedger/RESEARCH.md cites as the canonical factor-research scoring methods.

  • fit_predict_ridge(): single fold fit-and-predict.

  • evaluate_walk_forward(): glues the two together; returns per-fold metrics + a long-form DataFrame of out-of-sample predictions.

Out of scope here (deferred): hyperparameter tuning, classification head, panel models with ticker fixed effects, RL bolt-on. The current code is intentionally a baseline — it answers “is there any usable signal?”.

Walk-forward Ridge baseline over a session-level panel.

The panel must be sorted by session ascending. Rows with NaN target or feature values are dropped before training.

Parameters:

Called inside each fold on the train slice only — this avoids the look-ahead leakage that occurs when feature selection is run globally before splitting. The selector chooses among feature_cols.

newsmood.models.long_short_sharpe(y_true, y_pred, *, cost_bps=0.0)[source]#

Sharpe of a sign-based long-short portfolio.

For each session, go long if y_pred > 0, short if y_pred < 0, scale by 1; realized return is sign(y_pred) * y_true. Optional per-trade transaction cost in basis points is subtracted when the sign flips.

newsmood.models.walk_forward_splits(n, *, n_splits=5, min_train=30, embargo=1, test_size=None)[source]#

Yield (train_idx, test_idx) pairs for expanding-window CV.

Each test fold begins embargo indices after the last train index, so the forward-return horizon — which makes label r_t peek at price t + h — cannot leak across the train/test boundary as long as embargo >= h.

Parameters:

  • n (int) – Total number of (already chronologically-ordered) rows.

  • n_splits (int) – How many folds to produce.

  • min_train (int) – Minimum number of rows in the first training fold.

  • embargo (int) – Gap (in rows / sessions) between train and test.

  • test_size (Optional[int]) – Size of each test fold. Default: (n - min_train) // n_splits.
